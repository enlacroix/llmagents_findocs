# Схемы извлечения

По этим схемам модель понимает, какие поля достать из документа и в каком виде. Формат: JSON Schema 2020-12.

`default_scheme.json` подходит для любого документа: тип, номер, дата, валюта, период, стороны с реквизитами, ссылки на другие документы, позиции, итоги, подписи, печати и рукописные пометки. Для документов со своими таблицами есть отдельные схемы, они дополняют базовую.

## Какая схема у какого документа

## Дополнительные схемы

| Схема | Что добавляет к базовой |
|---|---|
| `company_card.json` | адрес для корреспонденции, учредители, руководство, подразделения |
| `order.json` | тема, пункты приказа, уполномоченное лицо, лимит полномочий |
| `bank_statement.json` | время формирования, остатки, обороты, операции |
| `branch_report.json` | строки по подразделениям, итоговая строка, нераспределенные поступления |
| `transfer_document.json` | статус УПД, сведения об отгрузке |
| `placement_registry.json` | размещения, параметры кампаний |
| `contract.json` | место заключения, предмет, регулярный платеж, порядок оплаты и отчетности |
| `contract_appendix.json` | мероприятия со сметой, согласование, аккредитованные лица |
| `participants_list.json` | мероприятия: дата, площадка, старший, участники, время |
| `payment_order.json` | назначение платежа, вид платежа и операции, очередность, отметки банка |
| `reconciliation_act.json` | сальдо, обороты и записи первой стороны, итоговая фраза |
| `transport_order.json` | ТС или груз, оценочная стоимость, маршрут, сроки, контактное лицо |
| `vehicle_transfer_act.json` | ТС, пробег, комплектность, документы, кто передал и принял |
| `insurance_policy.json` | ТС, риски, страховая сумма, франшиза, допущенные к управлению |
| `power_of_attorney.json` | доверенное лицо, полномочия, срок, право передоверия |
| `waybill.json` | автомобиль, водитель, задание, пробег и топливо |

Данные автомобиля (`vehicle`: модель, год, VIN, цвет, ЭПТС, номер) описаны в базовой схеме и используются во всех документах про машину.

## Правила заполнения

- В ответе есть все поля схемы. Если значения в документе нет, поле равно `null`, а список пустой.
- Значения записываются так, как напечатаны, даже если они противоречат другим документам.
- Даты в формате `YYYY-MM-DD`. Если в документе только день и месяц, год берется из периода документа.
- Суммы числами через точку, без пробелов. Знак минус сохраняется, если он напечатан.
- Ставка НДС в процентах: `22`.
- ИНН, КПП, ОГРН, счета и БИК записываются строкой из цифр, как прочитаны.
- Реквизиты стороны можно взять с ее печати.
- Названия организаций в коротком виде: `ООО «Чистые руки»`. ФИО представителя в именительном падеже.
- Строки таблиц в том же порядке, что и в документе.

## Сравнение с эталоном

Перед сравнением не учитываются регистр, пробелы, кавычки, тире и похожие русские и латинские буквы (`CH-00` и `СН-00`). Длинные тексты, например пункты приказа или текст печатей, сравниваются приблизительно, остальные поля точно.
