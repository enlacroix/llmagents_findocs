# Эталонная разметка

Правильные ответы для каждой страницы скана. По ним считаются метрики качества.

```json
{
  "source_file": "03_Счет_и_передаточный_документ.pdf",
  "page": 1,
  "schema": "default_scheme.json",
  "expected": { "...": "данные по схеме из ../schemes" }
}
```

Файл называется `<номер скана>_p<страница>_<тип документа>.json`.

В `expected` значения записаны так, как напечатаны в документе, даже если они расходятся с карточкой предприятия или другими документами.
